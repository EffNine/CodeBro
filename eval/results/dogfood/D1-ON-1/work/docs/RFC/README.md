# Request for Comments

Templates and accepted RFCs for CodeBro feature proposals.

## Template

| File | Description |
|------|-------------|
| [template.md](./template.md) | RFC template — use for all new RFCs |

## Registry

 RFCs are numbered sequentially as they are accepted. Create a new file for each RFC:

```
docs/RFC/rfc-XXX-title.md
```

## When to File an RFC

- New feature or phase
- Architecture change
- New dependency
- Public API modification
- Behavior change visible to users

## When an RFC Is NOT Needed

- Bug fixes restoring intended behavior
- Documentation updates
- Test additions
- Backward-compatible dependency bumps
