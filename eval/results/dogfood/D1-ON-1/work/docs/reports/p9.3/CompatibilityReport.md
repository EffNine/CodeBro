# Compatibility Report — P9.3

**Date:** 2026-08-06

## Overview

The Plugin SDK is designed for forward compatibility with all future plugin distribution models.

## Supported Plugin Sources

| Source | Type | Description |
|--------|------|-------------|
| `Local(path)` | Filesystem | Plugins from local directories |
| `Remote(url)` | Network | Plugins downloaded from marketplace |
| `Internal` | Binary | Plugins compiled into the binary |
| `AiGenerated` | AI | Plugins generated by AI at runtime |

## Version Compatibility

### Plugin Version
- Semantic versioning: `MAJOR.MINOR.PATCH`
- Each plugin declares its version

### SDK Version
- Each plugin declares `RequiredSdkVersion`:
  - `Exact(v)`: Must match exactly
  - `Minimum(v)`: Must be >= v
  - `Range(min..=max)`: Must be within range

### CodeBro Version
- Each plugin declares `SupportedVersionRange` for CodeBro
- Mismatch prevents loading

## Extension Points

The SDK supports future models without redesign:

1. **Marketplace**: Add `PluginSource::Remote(url)` + download + hash verification
2. **Enterprise**: Add custom `SecurityDomain` + policy enforcement
3. **AI Plugins**: Add `PluginSource::AiGenerated` + AI validation pipeline
4. **WebAssembly**: Add `PluginSource::Remote(wasm_url)` + WASM runtime

## API Stability

The public API is frozen for v1.0.0:
- `Plugin` trait: init, on_hook, shutdown, manifest, clone_box
- `PluginRegistry`: register, get, state, dependencies
- `HookDispatcher`: register, dispatch, hooks_for_phase
- `CapabilityModel`: register, has_capability, providers
- `PluginSandbox`: check, record_violation

No breaking changes to these interfaces in v1.x.
