# Architecture Decision Records

Templates and accepted ADRs for CodeBro architectural decisions.

## Template

| File | Description |
|------|-------------|
| [template.md](./template.md) | ADR template — use for all architectural decisions |

## Registry

 ADRs are numbered sequentially as they are accepted. Create a new file for each ADR:

```
docs/ADR/adr-XXX-title.md
```

## When to File an ADR

- Choosing between multiple technical approaches
- Defining a new pattern or convention
- Setting a threshold, limit, or constant
- Modifying an existing architectural constraint

## ADR Status Values

| Status | Meaning |
|--------|---------|
| **Proposed** | Being reviewed, not yet accepted |
| **Accepted** | Approved and active |
| **Deprecated** | Superseded by a later ADR |
| **Superseded** | Replaced by a newer ADR (reference the replacement) |
